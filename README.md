# Deaf Driver Assistance System Using 8051 Microcontroller

## Project Overview

The Deaf Driver Assistance System is an embedded system designed to assist hearing-impaired drivers by detecting nearby obstacles and providing visual warnings.

The system uses an 8051 microcontroller with sensors to monitor the left, front, and right sides of a vehicle. When an obstacle is detected, the corresponding LED is activated and a warning message is displayed on the LCD.

## Objectives

- Detect nearby obstacles around the vehicle.
- Identify the direction of detected obstacles.
- Provide visual alerts instead of audio warnings.
- Improve road safety for hearing-impaired drivers.
- Develop a simple and low-cost driver assistance system.

## Components Used

- AT89C51 / 8051 Microcontroller
- IR Sensors / Ultrasonic Sensors
- 16×2 LCD Display
- LEDs
- Crystal Oscillator
- Capacitors
- Resistors
- 5V Power Supply

## Working Principle

Three sensors are positioned to monitor the left, front, and right sides of the vehicle.

When an obstacle is detected, the sensor sends a signal to the 8051 microcontroller. The controller identifies the direction of the obstacle and provides a visual warning using LEDs and the LCD display.
